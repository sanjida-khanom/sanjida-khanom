<details>
<summary><b>Project details and tech stack</b></summary>
<br>

**Enterprise Knowledge Assistant**<br>
Grounded question answering over HR, finance and network-operations documents. Dense search and BM25 run in parallel and are fused with Reciprocal Rank Fusion, every answer carries citations, and refusal is a measured metric. Includes a LangGraph tool-using agent.<br>
<sub>LangChain · LangGraph · ChromaDB · FastAPI</sub>

**RAG Prompt Injection Demo**<br>
Reproduces an indirect prompt injection against a local RAG assistant: a hidden instruction in a reference document is retrieved and followed. Every stage is mapped to its MITRE ATLAS technique, then mitigated with sanitisation.<br>
<sub>Python · Ollama · sentence-transformers</sub>

**ML Classifier Evasion Demo**<br>
Black-box adversarial evasion against a locally trained classifier using IBM ART, then defended with adversarial training.<br>
<sub>PyTorch · IBM ART · scikit-learn</sub>

**Ransomware Detection**<br>
Hybrid static and dynamic analysis optimised with an Adaptive Grey Wolf Optimizer (A-GWO). Early detection fires from only the first three API calls.<br>
<sub>scikit-learn · LightGBM · SHAP · LIME</sub>

**Malicious URL Detection**<br>
Two-stage hierarchical multi-view graph framework with leakage-free GraphSMOTE and soft-voting fusion across three graph architectures.<br>
<sub>PyTorch Geometric · GCN · GAT · GraphSAGE</sub>

**HemaVision**<br>
Explainable white blood cell classification with an EfficientNetV2-B0 backbone and CBAM attention. Grad-CAM heatmaps feed automated Clinical Decision Reports. 99.04% validation accuracy.<br>
<sub>PyTorch · timm · CBAM · Grad-CAM</sub>

</details>
